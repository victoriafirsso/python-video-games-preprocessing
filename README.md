# python-video-games-preprocessing

**Python. Предобработка данных. Проект: Рынок видеоигр**

Проект выполнен в рамках курса Яндекс.Практикума «Аналитик данных». Проект является частью спринта «Python. Предобработка данных» и посвящён подготовке данных о продажах видеоигр к анализу: проверке типов, обработке пропусков и дубликатов, фильтрации по периоду и категоризации по оценкам. Цель — получить чистый срез данных за 2000-2013 годы для дальнейшего изучения истории продаж.

**Задачи проекта:** познакомиться с данными, проверить их корректность и провести предобработку, получив необходимый срез данных.

**Файлы:**
- `games_preprocessing.ipynb` — ноутбук с проектом;
- `new_games.csv` — исходные данные.

**Инструменты:** Python, pandas, Jupyter Notebook.
