# Python. Предобработка данных. Проект: Рынок видеоигр

Проект выполнен в рамках курса Яндекс.Практикума «Аналитик данных». Проект является частью спринта «Python. Предобработка данных» и посвящён подготовке данных о продажах видеоигр к анализу: проверке типов, обработке пропусков и дубликатов, фильтрации по периоду и категоризации по оценкам.

**Цель проекта:** познакомиться с данными, проверить их корректность и провести предобработку, получив необходимый срез данных за 2000-2013 годы для дальнейшего изучения истории продаж.

## Описание данных

Файл `/datasets/new_games.csv` содержит информацию о продажах игр разных жанров и платформ, а также пользовательские и экспертные оценки игр.

| Столбец | Описание |
|---|---|
| `Name` | название игры |
| `Platform` | название платформы |
| `Year of Release` | год выпуска игры |
| `Genre` | жанр игры |
| `NA sales` | продажи в Северной Америке (млн проданных копий) |
| `EU sales` | продажи в Европе (млн проданных копий) |
| `JP sales` | продажи в Японии (млн проданных копий) |
| `Other sales` | продажи в других странах (млн проданных копий) |
| `Critic Score` | оценка критиков (от 0 до 100) |
| `User Score` | оценка пользователей (от 0 до 10) |
| `Rating` | рейтинг организации ESRB (Entertainment Software Rating Board), которая определяет рейтинг компьютерных игр и присваивает им возрастную категорию |

## Поставленные задачи

- Отобрать данные по времени выхода игры: период с 2000 по 2013 год включительно.
- Категоризовать игры по оценкам пользователей и экспертов (критиков) на три категории:
    - **высокая оценка** — от 8 до 10 и от 80 до 100, включая правые границы интервалов;
    - **средняя оценка** — от 3 до 8 и от 30 до 80, не включая правые границы интервалов;
    - **низкая оценка** — от 0 до 3 и от 0 до 30, не включая правые границы интервалов.
- Выделить топ-7 платформ по количеству игр, выпущенных за весь требуемый период.

## План работы

1. Проверка ошибок в данных и их предобработка: названия столбцов, типы данных, пропуски, явные и неявные дубликаты
2. Фильтрация данных
3. Категоризация данных
4. Выводы

## Что сделано

- Загружены и изучены данные о 16 956 играх.
- Проведена предобработка: названия столбцов приведены к snake_case, исправлены типы данных, обработаны пропуски, удалены дубликаты. Удалено 523 строки (3,08%), осталось 16 433.
- Отобраны игры 2000-2013 годов (12 771 игра).
- Добавлены категории оценок пользователей и критиков (высокая, средняя, низкая).
- Выделены топ-7 платформ по количеству игр: PS2, DS, WII, PSP, X360, PS3, GBA.

## Основные наблюдения

- Преобладает средняя оценка: у 63% игр по оценкам пользователей и у 75,7% по оценкам критиков.
- Низкие оценки встречаются редко: 1,8% у пользователей и 0,8% у критиков.
- Лидеры по числу игр, PS2 и DS, почти равны (2 126 и 2 117), а на топ-7 платформ приходится 76% игр среза.
